is a wish list. Method and rationale: `references/research-workflows.md` section 3.

## Sufficiency check before closing the plan

Tick all seven or the plan stays open (`references/research-workflows.md` section 7).

```
[ ] 1. Answered as a conclusion, not the least-excluded guess
[ ] 2. Every source class searched, or its unavailability documented with specifics
[ ] 3. Independent corroboration for each key assertion, or an explicit statement that
       no independent source can exist for this place and period
[ ] 4. Every competing candidate and interpretation eliminated on evidence
[ ] 5. Every conflict resolved in writing
[ ] 6. Saturation: recent searches return only what I already hold
[ ] 7. Hostile-reader test: no skipped record class, untried variant, or untested alternative
```

Failing any of them, close it as an open question instead:

```

                     2.
Blocked by:          [access / cost / language / a prior identity question / nothing]
Reopen when:         [applicable re-search triggers]
```
